# services/

Data-access and platform services (proposal §8.2, §11).

- `firebase/` — Firebase client SDK init (Auth, Firestore, Storage).
- `api/` — HTTP client for the secure AI backend.
- `database/` — Expo SQLite offline cache and drafts.
- `notifications/` — local study reminders.

PLACEHOLDER. Not implemented. `firebase/client.js` is a stub that throws a
clear configuration error if required env vars are missing.
