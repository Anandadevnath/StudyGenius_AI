# assets/

- `images/` — screen imagery (splash, illustrations).
- `icons/` — app icon (1024×1024), adaptive icon, favicon (proposal §19.1).
- `fonts/` — Plus Jakarta Sans and Inter font files (proposal §12.6).

PLACEHOLDER. Real assets (app icon, feature graphic, fonts) are produced in
later phases. The `.png` files here are 1×1 placeholders so `app.json`
resolves during setup and verification.
